# Gut Reset, wave 4: the metaphors

The last 13 cut-paper images in the Gut Reset course (2148514926). Generated
2026-10-27 on `nano_banana_2_1`, 16:9, 2k, `thinking_level: high`.

## These were designed from the copy, not from the filename

A metaphor that does not land is worse than no image, which is what the
orchestra taught us in Gut Foundations. So every one of these 13 lesson bodies
was read first, and each frame was designed against the sentence it sits beside.

That turned out to matter, because **the copy names several of these analogies
outright**. The leaky gut lesson contains, in Alina's own voice:

> It is a screen door. It is supposed to let the air through and keep everything
> else out. When the mesh tears, the door still looks like a door and still
> swings on its hinges, but it has stopped doing the one job it had. The problem
> is not what is on the porch. The problem is the mesh.

So the picture is not decorating the lesson, it is the thing the lesson already
says. All 13 original concepts survived the check. It was the cut-paper
execution Steve rejected, not the thinking behind it.

## Three the copy forced a change to

Reading the lesson first changed the brief in three places. None of these would
have been visible from the filename alone.

**`see-your-doctor`.** A closed gate shot plainly reads "you are blocked", which
is the exact opposite of what the page says:

> Getting checked is not giving up on this work. It makes sure we are working on
> the right thing.

So the land beyond the gate is the brightest part of the frame, the path visibly
carries on, and there is no padlock, chain or barrier of any kind. The gate is a
pause on the way, not a dead end.

**`against-your-bacteria`.** The page is explicit that it is not asking for fear:

> The aim is not a life of avoidance. It is knowing what takes a toll, and
> knowing how to recover afterward.

So the bed had to stay overwhelmingly healthy with one local dead patch. The
first attempt put bare soil at the edge of frame next to a timber board, which
read as an ordinary garden path rather than damage, and the metaphor collapsed.
Re-shot from directly overhead with green filling every edge and a single
cracked patch ringed by growth on all sides.

**Counts.** Two of these carry a number that the copy states:

| Image | The copy says | The frame has |
|---|---|---|
| `reintroduction-tracker` | "Four rows for four foods" | 4 blank tags, 4 empty hooks beside them |
| `reintroducing-your-pattern` | "Read your own and ignore the other four" | 5 keys, each a different bit pattern |

Both were counted at native resolution rather than trusted. Wave 3 shipped four
alt texts that stated a count the photograph did not have, and that is not a
mistake worth making twice.
