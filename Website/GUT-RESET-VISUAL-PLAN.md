## 1. The scale problem, stated first

The mini course is **14 lessons**. The Gut Reset is **62 published lessons**
across 9 modules. It is more than four times the size.

A hero on every lesson is roughly 62 generated images, about 400 Higgsfield
credits (affordable against 6,573), but it is also 62 images for Steve to upload
and a very long placement run. Doing it in one pass is not the right shape.

The plan below is tiered so the course looks finished early rather than evenly
half-done everywhere.

## 2. Three kinds of image, and only one of them gets generated

This is the most useful distinction in the whole plan.

### Type A: cut-paper heroes (generated, uploaded, placed)

Same locked style string as the mini course. These carry mood and metaphor.

### Type B: pattern portraits (generated, uploaded, placed)

Five images, one per gut pattern. These earn their keep more than anything else
here, because the course repeats its five-way structure across the pattern
pages, the five shopping lists, the five meal plans, and the "This Week For Your
Pattern" sections in all four weeks. **Five images cover roughly twenty
surfaces** and give each pattern a visual identity a member starts to recognize.

### Type C: information graphics (built inline, NOT generated, no upload)

Image generators produce gibberish wherever a label is required. Ask one for "a
14-day reintroduction schedule" and it returns beautiful nonsense.

So anything needing real text gets **built directly in the lesson body as HTML
and CSS**, in the website palette. That is better in every way that matters:

- **No upload step.** The agent can build and place these immediately
- Responsive on a phone, where a wide image of a table is unreadable
- Editable later without regenerating anything
- Accessible to a screen reader
- Selectable and searchable text

**This removes the upload bottleneck for the single most useful visual work in
the course.** It can start today.

## 3. The conflict in "all new images"

Steve asked for no reuse from the $27 course. There is one place where that
collides with something locked.

The five archetype analogies in CLAUDE.md are **brand property, not mini-course
assets**: the car with the engine timing off, the damaged screen door, the
squatters, the cold stove, the flooded basement. The Gut Reset's own written
copy uses them. Week 1's barrier lesson contains the screen door passage
verbatim. Week 3's liver lesson runs the sink and drain.

So if the $147 course illustrates the Reactive pattern with something that is
not a screen door, the picture argues with the words on the same page.

**Recommendation: new artwork, same analogies.** A different screen door, seen
from a different angle, at a different time of day, in a different house. A
different engine. A different flooded basement. Every file is new, nothing is
reused, and the locked analogies stay locked.

The alternative, inventing five fresh analogies for the more expensive course,
breaks a thing CLAUDE.md calls locked and would need Alina's sign-off, not just
Steve's.

## 5. Tier 2: information graphics (8 to 10, built inline, no upload)

Where the $147 course can genuinely out-class the $27 one.

| Graphic | Lesson | What it does |
|---|---|---|
| The four-week arc | Start Here, How This Course Works | subtract, rebuild, digestion, widen, then reintroduce. One timeline that orients the whole purchase |

| The fiber ramp | Week 1 or Week 2 | 12g to 30g over weeks, not days, which is the advice people most often get wrong |
| The reintroduction schedule | How Reintroduction Works | a 14-day grid: which food, which day, what to watch for, when to stop |
| Reintroduction result tracker | Your Reintroduction Tracker | where the member records outcomes. Currently a PDF download only |
| The plant count | Week 4 | 30 plants a week, with a tally |
| What each test actually shows | Testing, And When It Is Worth It | GI-MAP against the other four, what each answers, what it costs |
| Timing of supplements | The Supplement Reference | with food, empty stomach, away from medication |
